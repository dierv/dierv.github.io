# dierv.github.io

Sito principale di GitHub Pages: https://dierv.github.io/

Serve soprattutto per **app-ads.txt** (https://dierv.github.io/app-ads.txt), che AdMob cerca nella
radice del "sito web dello sviluppatore" indicato nelle schede di Google Play e App Store.

Una sola riga vale per tutte le app dello stesso account AdMob (pub-2017539960623897):

```
google.com, pub-2017539960623897, DIRECT, f08c47fec0942fa0
```

Per ogni app con annunci: negli store mettere come sito web una pagina sotto `https://dierv.github.io/`
(per esempio `https://dierv.github.io/save-the-ufo-sito/`). AdMob controlla il file entro qualche giorno.
